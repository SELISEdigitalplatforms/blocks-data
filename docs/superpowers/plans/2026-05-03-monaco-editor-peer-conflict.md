# Monaco editor peer dependency fix

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve `ERESOLVE` during `npm ci` in Docker by aligning `monaco-editor` with `monaco-graphql`'s peer range so CI installs cleanly without `--legacy-peer-deps`.

**Architecture:** `monaco-graphql@1.7.x` (pulled by root and by `graphiql` → `@graphiql/react`) declares `monaco-editor` peer `>= 0.20.0 < 0.53`. The app had `monaco-editor@^0.54.0`, which violates that upper bound. Pin the app to `^0.52.2` (latest 0.52.x satisfies `< 0.53`) and regenerate `package-lock.json` so a single compatible tree satisfies `@monaco-editor/react` (peer `>= 0.25.0 < 1`).

**Tech Stack:** npm, Vite client, monaco-editor, monaco-graphql, @monaco-editor/react, graphiql.
